# Lab 2 — Database Integration with JDBC

## Overview
This lab extends the IgirePay system by integrating PostgreSQL database storage using JDBC.

## Technologies
- Java
- JDBC
- PostgreSQL
- Maven

## Features
- Customer CRUD operations
- Account management
- Transaction management
- Duplicate transaction validation
- DAO Pattern implementation

## Database Tables
- customers
- accounts
- transactions
- processed_requests

## Security Features
- PreparedStatement usage
- SQL injection prevention
- Transaction reference validation

## DAO Classes
- CustomerDAO
- AccountDAO
- TransactionDAO
- ProcessedRequestDAO

## Key Learning Objectives
- Understand JDBC database connectivity
- Practice DAO architecture
- Secure database applications
- Implement reliable transaction workflows
