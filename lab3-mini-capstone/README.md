# Lab 3 — IgirePay Mini Capstone Project

## Overview
This project is a JavaFX-based fintech application inspired by MTN Mobile Money.

The system allows users to:
- Register customers
- Manage wallet accounts
- Deposit and withdraw money
- Transfer funds
- View transaction history
- Prevent duplicate transactions using unique reference IDs

## Technologies Used
- JavaFX
- JDBC
- PostgreSQL
- Maven
- Git & GitHub

## Architecture
The application follows layered architecture:
- UI Layer (JavaFX)
- Controller Layer
- Service Layer
- DAO Layer
- Database Layer

## Features
### Authentication
- PIN creation
- PIN validation
- PIN change

### Wallet Management
- Wallet accounts
- Savings accounts
- Balance checking

### Transactions
- Deposits
- Withdrawals
- Transfers
- Transaction history

### Security
- Duplicate transaction prevention
- PreparedStatement protection
- Exception handling

## Bonus Features Planned
- Transaction rollback
- Role-based access
- Account locking
- Transaction reports

## Project Goal
To simulate a secure and reliable fintech payment system using Java backend technologies.
