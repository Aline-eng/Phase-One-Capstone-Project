# Phase One Capstone Project

## Project Overview
This repository contains all labs and the mini capstone project for the Advanced Java Backend Phase One assessment.

The project is based on the IgirePay Wallet & Payment Management System, a fintech-inspired application that simulates secure digital payment processing similar to MTN Mobile Money.

## Technologies Used
- Java
- JavaFX
- JDBC
- PostgreSQL
- Maven
- Git & GitHub
- Object-Oriented Programming

## Repository Structure

```text
Phase One Capstone Project/
│
├── lab1-oop/

```

## Labs Description

### Lab 1 — Object-Oriented Programming
Focuses on:
- Inheritance
- Encapsulation
- Polymorphism
- Java Collections
- Duplicate transaction prevention

### Lab 2 — JDBC & Database Integration
Focuses on:
- PostgreSQL integration
- JDBC
- DAO Pattern
- CRUD Operations
- PreparedStatement security

### Lab 3 — Mini Capstone Project
Complete JavaFX fintech application implementing:
- Authentication
- Wallet management
- Money transfers
- Transaction history
- Savings management
- Duplicate transaction prevention
