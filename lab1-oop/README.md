# Lab 1 — Object-Oriented Design in Action

## Overview
This lab focuses on implementing core Object-Oriented Programming concepts in Java using the IgirePay Wallet System scenario.

## Concepts Covered
- Encapsulation
- Inheritance
- Polymorphism
- Method Overriding
- Java Collections

## Main Classes
- Account
- WalletAccount
- SavingsAccount
- Customer
- Transaction

## Features
- Customer account management
- Transaction processing
- Duplicate transaction detection
- Transaction history tracking

## Collections Used
- List
- Set
- Map

## Key Learning Objectives
- Apply OOP principles in real-world scenarios
- Understand inheritance and polymorphism
- Manage data using Java Collections
- Prevent duplicate transactions using reference IDs
